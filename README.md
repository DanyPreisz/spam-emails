# Detección de Spam en Emails

Proyecto de clasificación de texto listo para Google Colab. Incluye EDA, TF-IDF, modelos y SHAP.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/spam-emails/blob/main/spam_emails_colab.ipynb)

## Contenido

- EDA (distribución, longitud de mensajes)
- TF-IDF vectorizer
- Modelos: Logistic Regression, Random Forest
- Matriz de confusión + classification report
- Palabras más importantes (coeficientes)
- **SHAP** (ejemplo)
- Conclusiones

Dataset: SMS Spam Collection

Rango esperado: Accuracy ~0.97–0.99 | ROC-AUC ~0.98–0.99
